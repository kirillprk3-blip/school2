# Мост VK ↔ Telegram

Бот, который синхронизирует переписку между беседой ВКонтакте и группой/чатом
в Telegram: сообщения из VK автоматически приходят в Telegram и наоборот.
Школьный проект для беседы класса.

## Возможности

- Привязка любого количества независимых пар VK-беседа <-> TG-чат (мультитенантно,
  один бот обслуживает много классов/групп одновременно).
- Привязка группы Telegram кодом из VK - без слэш-команд, просто отправкой кода
  обычным сообщением, либо через deep link, если бота ещё нет в группе.
- Обязательная верификация: TG-пользователь должен один раз подтвердить, что
  владеет конкретной страницей VK (`/link_vk`), прежде чем сможет привязать чат
  или писать в VK - без этого кто угодно мог бы подделать отправителя через
  `/setname`.
- Двусторонняя пересылка текста, фото, голосовых, видео, стикеров, с reply и
  редактированием сообщений.
- Кликабельное упоминание отправителя в VK для подтверждённых профилей.
- Полная история сообщений и статистика активности; команды `/whois` (кто
  реально автор пересланного сообщения) и `/report` (сводка + CSV) для админов.

## Стек

Python 3.12, aiogram 3 (Telegram), vkbottle (VK Bots LongPoll), aiosqlite
(без ORM, прямой SQL).

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
```

## Настройка `.env`

```bash
cp .env.example .env
```

| Переменная        | Описание                                                              |
|--------------------|------------------------------------------------------------------------|
| `TG_BOT_TOKEN`     | Токен Telegram-бота от [@BotFather](https://t.me/BotFather)            |
| `VK_GROUP_TOKEN`   | Токен сообщества VK с правами `messages` и `manage`                    |
| `VK_GROUP_ID`      | ID сообщества VK                                                       |
| `TG_API_BASE_URL`  | Опционально: адрес прокси перед `api.telegram.org` (например, свой Cloudflare Worker), если Telegram Bot API заблокирован напрямую с хостинга |

## Запуск

```bash
python main.py
```

## Тесты

```bash
python -m pytest tests/ -v
```

## Структура проекта

| Файл             | Назначение                                            |
|-------------------|---------------------------------------------------------|
| `main.py`         | Точка входа: запуск, graceful shutdown, реконнект        |
| `config.py`       | Загрузка конфигурации из `.env`                           |
| `database.py`     | Схема БД (сырой SQL, без ORM) и CRUD-функции               |
| `tg_handlers.py`  | Хэндлеры Telegram-бота (aiogram 3)                         |
| `vk_listener.py`  | Слушатель VK Bots LongPoll                                 |
| `vk_sender.py`    | Отправка сообщений в VK                                    |
| `router.py`       | Двусторонняя маршрутизация сообщений/медиа между VK и TG   |
| `deploy/index.js` | Cloudflare Worker - прокси перед `api.telegram.org` для хостингов, где Telegram заблокирован напрямую |
